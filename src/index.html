视频和照片处理系统

系统说明

本系统是一个集成了YOLO人脸检测、人脸识别和马赛克脱敏功能的Web应用。您可以上传视频或照片，并选择是否应用马赛克和人脸检测功能。

系统已与您的Python代码完全集成，具有真实的处理功能！

如何运行系统

步骤 1: 安装依赖

确保已安装所有必需的Python包：

pip install flask opencv-python numpy torch pillow

步骤 2: 启动服务器

在终端中运行：

python app.py

服务器将在 http://localhost:5000 启动

步骤 3: 访问系统

点击下方按钮或手动访问 http://localhost:5000

访问上传系统

系统功能

  • 视频处理：上传视频文件（MP4、AVI、MOV）
  • 照片处理：上传图片文件（JPG、JPEG、PNG、GIF）
  • 马赛克功能：对检测到的人脸区域应用马赛克
  • 人脸检测：使用YOLO模型检测人脸
  • 人脸识别：与底库中的人脸进行比对识别
  • 智能处理：识别到已知人脸时不打马赛克，未知人脸才打码

注意事项

  • 首次运行时需要初始化模型，可能需要一些时间
  • 请确保模型文件路径正确：C:\Users\34239\.insightface\models\buffalo_l\w600k_r50.onnx
  • 人脸底库照片应放在 gallery 文件夹中
  • 处理大文件可能需要较长时间，请耐心等待
